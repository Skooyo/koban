The mascot: Mon

A koban is an old Japanese gold coin: a tall oval with hammer lines across it. That is already Koban's logo, so the mascot is the logo with a face. "Mon" was the small coin of the same era. It is a name proposal; change it if you like.

Mon has Dusk's character: half-closed eyes, a flat mouth, a dry voice. It is a flat vector, so it costs almost nothing to load. Dusk is a 3D model of about 7,000 triangles.

  • Rule 1Mon never stands next to a money figure and never replaces an instruction. The plain sentence comes first; Mon's line is extra.
  • Rule 2One Mon per screen at most, and only in states: empty lists, tracking off, all checked, errors, first run.
  • Rule 3A switch in Settings hides Mon. The plain sentences stay.

Errors and empty lists

This is where Mon works. Every error and empty state follows one pattern: what happened, why, and the next step as a button.

  • H9 Recognize, diagnose and recover from errors · review "later": Fix sheet hides a failed readThe message names the cause ("too dark") and gives two ways forward. It never says "Something went wrong".
  • H10 HelpAn empty list explains how it fills up, and the button to fill it is right there.
  • Mascot rule 1Mon's line is in grey italics under the plain sentence. A person who reads only the bold text still knows what to do.
